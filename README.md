# আপনার ওয়েবসাইট — ব্যবহার নির্দেশিকা

এই ফোল্ডারে আছে:
- `index.html` — হোমপেজের কাঠামো
- `project.html` — প্রতিটা প্রজেক্টের বিস্তারিত পেজ (একটাই ফাইল, সব প্রজেক্টের জন্য)
- `projects-data.js` — **প্রজেক্টের সব তথ্য এখানে** (নাম, ছবি, বিবরণ) — নতুন প্রজেক্ট যোগ করতে শুধু এই ফাইলটা বদলাতে হবে
- `style.css` — রঙ, ফন্ট, লেআউট
- `script.js`, `project.js` — পেজ দুটো চালানোর কোড, সাধারণত হাত দেওয়ার দরকার নেই
- `images/` — লোগো ও সব প্রজেক্টের ছবি

## নতুন প্রজেক্ট যোগ করা (সবচেয়ে গুরুত্বপূর্ণ অংশ)

আর কোনো HTML লেখার দরকার নেই। শুধু দুইটা কাজ করলেই একটা নতুন প্রজেক্ট
হোমপেজে এবং তার নিজের বিস্তারিত পেজে দেখা যাবে:

**১. ছবি যোগ করুন**
আপনার প্রজেক্টের ছবি একটা ভালো নামে (যেমন `project-7.jpg`, স্পেস বা
বাংলা অক্ষর ছাড়া) `images/` ফোল্ডারে আপলোড করুন।

**২. `projects-data.js` ফাইলে তথ্য যোগ করুন**
এই ফাইলটা খুললে দেখবেন প্রতিটা প্রজেক্ট এভাবে লেখা:
```js
{
  id: "kadam-house",
  title: "Kadam House",
  location: "Dhanmondi",
  year: "2024",
  category: "Residential — new build",
  image: "project-1.jpg",
  description: [
    "প্রথম প্যারাগ্রাফ।",
    "দ্বিতীয় প্যারাগ্রাফ।"
  ],
  gallery: []
}
```
তালিকার শেষ প্রজেক্টের পর একটা কমা (`,`) দিয়ে এভাবে নতুন একটা `{ ... }`
ব্লক যোগ করুন, নিজের তথ্য দিয়ে ঘরগুলো পূরণ করে। `id` অংশে ইংরেজি ছোট
হাতের অক্ষর আর হাইফেন ছাড়া কিছু ব্যবহার করবেন না, এবং প্রতিটা প্রজেক্টের
`id` আলাদা হতে হবে। `description`-এ যত ইচ্ছা প্যারাগ্রাফ যোগ করা যায়।
`gallery`-তে চাইলে আরও অতিরিক্ত ছবির নাম দিতে পারেন (না দিলে `[]` রেখে দিন)।

ফাইলটার শুরুতে বাংলায় বিস্তারিত উদাহরণ ও ব্যাখ্যা কমেন্ট আকারে লেখা আছে।

সেভ করে GitHub-এ শুধু `projects-data.js` আর নতুন ছবি(গুলো) আপলোড করলেই
হবে — হোমপেজের গ্রিড আর ডিটেইল পেজ নিজে থেকেই আপডেট হয়ে যাবে।

## অন্য লেখা পাল্টানো
`index.html`-এ Studio/Approach/Contact সেকশনের লেখা সরাসরি বদলে দিতে
পারবেন — HTML ট্যাগ (< > চিহ্নযুক্ত অংশ) না ঘেঁটে শুধু লেখাগুলো বদলান।

## GitHub-এ আপলোড করা — সম্পূর্ণ রিপ্লেস (প্রথমবার বা বড় পরিবর্তনের সময়)
1. রিপোর **Settings → নিচে Danger Zone → Delete this repository** দিয়ে
   পুরনো রিপো মুছে ফেলুন
2. নতুন রিপো বানান, নাম দিন ঠিক আপনার ইউজারনেম + `.github.io`
   (যেমন `grihonaksha.github.io` — **i-o**, বানান খেয়াল করে) এবং
   **Public** সিলেক্ট করুন
3. এই zip আনজিপ করলে যে `mysite` ফোল্ডার পাবেন, তার **ভেতরের সবকিছু**
   (README বাদে) — `index.html`, `project.html`, `projects-data.js`,
   `style.css`, `script.js`, `project.js`, আর পুরো `images` ফোল্ডার —
   একসাথে সিলেক্ট করে **Add file → Upload files**-এ দিন
4. **Commit changes**
5. **Settings → Pages** থেকে Branch `main` সিলেক্ট করে Save করুন
6. ২-৫ মিনিট পর সাইট লাইভ হবে

## ফাইল/ফোল্ডার নিয়ে সাবধানতা
- ছবি অবশ্যই **`images`** ফোল্ডারের ভেতরে থাকতে হবে (নাম হুবহু `images`,
  `image` নয় — এই ভুলের কারণেই আগে ছবি দেখাচ্ছিল না)
- ফাইলের নামে স্পেস বা বাংলা অক্ষর রাখবেন না — শুধু ইংরেজি, সংখ্যা, হাইফেন
- বড়/ছোট হাতের অক্ষর মিলিয়ে রাখুন (`Logo.jpg` আর `logo.jpg` আলাদা ফাইল)
- সাইট দেখার আগে ব্রাউজারে **Ctrl+Shift+R** (হার্ড রিফ্রেশ) দিন
